# DeepUncertainty
This project is shared framework code of deep uncertainty management approach for construction. It has two integrated parts,  i.e., Markov Bayesian inference (Markov Chain Monte Carlo-based Bayesian inference) and Deep Uncertainty analysis.
The framework is general and you are free to follow this to develop project specific code. You can also extend this for advanced deep uncertainty management for construction.
